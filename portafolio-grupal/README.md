# Portafolio Terabyte

Sitio web de presentación del proyecto **Terabyte**, desarrollado con tecnologías web básicas: HTML, CSS y JavaScript.

El repositorio contiene la estructura principal del sitio, sus estilos, la lógica de interacción y el recurso gráfico de marca.

## 📂 Estructura del proyecto

```text
portafolio-terabyte/
├── index.html   # Estructura y contenido de la página
├── style.css    # Estilos, diseño y adaptación visual
├── script.js    # Funcionalidades e interacciones con JavaScript
├── logo.svg     # Recurso gráfico / logotipo
└── Readme.md    # Inforamacion sobre el Portafolio Terabyte 
```

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura y contenido del sitio.
- **CSS3:** presentación visual y estilos.
- **JavaScript:** comportamiento e interactividad.

## 🚀 Cómo ejecutar el proyecto

Abre el link del Portafolio [https://portafolio-terabyte.onrender.com](https://portafolio-terabyte.onrender.com)

## 📌 Estado del proyecto

Proyecto en desarrollo. Las secciones y funcionalidades disponibles dependen de la versión actual del código fuente.
